# موسوعة التفسير بالمأثور المطوّرة

تطوير وإخراج: منصة مدارج.

واجهة واحدة تعرض خلاف السلف في تفسير كل آية مرتبًا بحسب الأقوال، مع قائلي كل قول وطبقاتهم، وترجيحات خمسة من المحققين (الطبري، ابن عطية، ابن كثير، ابن تيمية، ابن القيم) وتعليلها وقواعد ترجيحهم.

## الفتح

- **`موسوعة التفسير بالمأثور المطوّرة - ملف واحد.html`**: ملف مستقل يكفي وحده. يُنقل إلى أي حاسوب أو جوال ويُفتح بالمتصفح بلا إنترنت.
- **`موسوعة التفسير بالمأثور المطوّرة.html`**: النسخة التي تعمل مع مجلدَي `بيانات` و`مشد` بجوارها.

## الأصول

مبنيّة على «موسوعة التفسير المأثور» لمركز الدراسات والمعلومات القرآنية، و«جامع البيان» للطبري (ط هجر)، و«أقوال السلف في التفسير من جامع البيان لابن جرير» للدكتور عبد الرحمن المشد. وعمل منصة مدارج فيها: الترتيب والربط والإخراج، والمادة العلمية لأصحابها.

**هذا المستودع خاص.** فيه صور جداول كتاب مطبوع ونصوص موسوعة منشورة، وهو للاستعمال الشخصي في المذاكرة والتحضير والبحث، وليس للنشر العام إلا بإذن أصحاب الأصول.
